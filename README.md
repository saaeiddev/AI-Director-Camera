# AI Director Camera

Native Android AI-assisted cinematography camera.

## APK Build

Every push to `main` runs the GitHub Actions workflow **Build Android APK**.
A successful run publishes an artifact named **AI-Director-Camera-APK** containing:

- `AI-Director-Camera.apk`
- `AI-Director-Camera.apk.sha256`

The source snapshot used by the workflow is stored in `AI-Director-Camera-Source.zip`.
